# Nexora Digital — Creative Digital Agency & Engineering Studio

A high-impact, creative digital agency web application built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Highlights & Features

- **High-End Cyber / Agency Aesthetic:** Deep navy canvas (`#0B0F19`), neon purple and cyan accents, futuristic typography, and glassmorphic cards.
- **Dynamic Animated Hero:** Interactive agency telemetry counters ($180M+ Capital, 140+ Shipped, 99.4% On-Time, 4.9/5 Rating) with client ecosystem ticker and dual call-to-actions.
- **Interactive Case Study Portfolio:** Category filtering (FinTech, AI & SaaS, E-Commerce, Web3) with detailed modal popups detailing the challenge, technical solution, deployed stack, and metrics.
- **Interactive Technology Stack Explorer:** Interactive switcher across Frontend, Backend, AI & Data Intelligence, and DevOps infrastructure.
- **Velocity Sprint Pricing Engine:** Standalone sprint vs. Annual Retainer interactive toggle switch with transparent deliverables and best-value highlights.
- **Interactive FAQ Accordion:** Clean, animated accordions addressing intellectual property, sprint cadence, and communications.
- **Lead Generation Brief Form:** Multi-field validated initiative form with pre-filled budget selector and instant WhatsApp studio dispatch link.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or pnpm

### Installation
```bash
# Navigate to project directory
cd agency-website

# Install dependencies (if not already installed)
npm install

# Start development server
npm run dev
```

The application runs locally at `http://localhost:3004` (or next available port).

### Production Build
```bash
# Compile TypeScript and bundle assets
npm run build

# Preview production build locally
npm run preview
```
